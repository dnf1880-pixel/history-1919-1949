# boge.net.cn 注册 · 备案 · 上线 操作手册

> 目标：把现有站点绑到自有域名 `www.boge.net.cn`
> 全程费用：域名 ¥25—33/年（建议买 3 年 ≈ ¥101），备案与托管均免费
> 必须您本人做的只有两步：**买域名** + **人脸核验**；其余我来

---

## 总览：三个阶段

| 阶段 | 做什么 | 谁做 | 耗时 |
|---|---|---|---|
| 一 | 买域名 + 实名认证 | 您（付款） | 3 分钟 + 等 3 天 |
| 二 | ICP 备案 | 您（人脸核验） | 7—20 天 |
| 三 | 绑定域名 | 我（一条命令） | 5 分钟 |

**重要：备案期间现在能用的地址继续可用，不影响任何人访问。**

---

## 一、购买域名（约 3 分钟）

### 1.1 下单

1. 打开 **https://buy.cloud.tencent.com/domain**
2. 微信或 QQ 扫码登录腾讯云账号（没有就注册一个，免费）
3. 搜索框输入：`boge.net.cn`
4. 加入购物车
5. **年限选 3 年**（¥25—33/年，多年更划算，也省得忘续费）
6. 结算付款

### 1.2 立刻做实名认证（关键）

1. 进腾讯云控制台 → 搜「域名」→ 域名列表
2. 找到 `boge.net.cn` → 点「未实名」提示
3. 上传**身份证正反面**照片（拍清楚，四角完整）
4. 提交，等审核（一般几小时到 1 天）

### 1.3 等 3 天（硬性规定，急不得）

实名通过后**必须再等 3 个工作日**。原因：工信部数据库要 3 天才同步到您的实名信息。
**不满 3 天就提交备案，管局查不到实名记录，直接驳回。** 这是最常见的坑。

---

## 二、ICP 备案（7—20 天，全程免费）

### 2.1 进备案入口

腾讯云控制台 → 搜索「备案」→ **首次备案**

### 2.2 准备材料

| 材料 | 说明 |
|---|---|
| 身份证 | 正反面清晰照片 |
| 手机号 | 接收管局验证码（务必本人实名手机号） |
| 微信 | 扫码进「腾讯云备案」小程序，做人脸核验 |

### 2.3 关键填写项（照抄）

| 项目 | 填什么 |
|---|---|
| 备案主体 | **个人**（您本人） |
| 域名 | `boge.net.cn` |
| **网站名称** | **`1919历史学习`** |
| 网站内容/服务 | **`历史教育学习`** |
| 服务器 | 选 **CloudBase**（您的环境就在里面） |
| 网站负责人 | 您本人（信息要和域名实名完全一致） |

### 2.4 三个最容易被驳回的点

| 坑 | 怎么避 |
|---|---|
| **网站名称含禁用词** | 绝对不能出现「中国」「中华」「国家」「政府」等词。用「1919历史学习」这种就稳 |
| **主体信息与域名实名不一致** | 备案填的姓名、证件号，必须和域名实名认证的一模一样 |
| **域名实名不满 3 天** | 见 1.3，等够了再提交 |

### 2.5 流程与时长

1. 提交资料 → 腾讯云初审（**1—2 个工作日**，可能打电话核实，注意接听）
2. 初审通过 → 工信部短信核验（**24 小时内必须点**，否则作废）
3. 管局审核（**最长 20 个工作日**，一般 7—10 天）
4. 通过 → 收到**备案号**（形如 `鄂ICP备2026XXXXXX号`）

---

## 三、绑定域名（备案通过后，我来做）

### 3.1 您要做的

备案一下来，把**备案号**发我，说一声「备案好了」。

### 3.2 我执行

一条命令绑上去：

```bash
tcb domains add boge.net.cn -e workbuddy-d4g9xyztobd4d2920
```

再配好 HTTPS 证书（腾讯云自动签发，免费），完成后访问地址变成：

**https://www.boge.net.cn**

## 常见问题

**Q：备案期间站点还能访问吗？**
A：能。现在这个 CloudBase 地址继续可用，不受任何影响。备案只是为了让新域名能用国内节点。

**Q：可以不备案吗？**
A：不行。CloudBase 是上海节点（中国大陆境内），域名必须备案，这是工信部规定。不备案绑定会被拦。

**Q：备案要钱吗？**
A：免费。腾讯云提供免费备案服务，一分钱不收。

**Q：多久能全部搞定？**
A：最快约 10 天（3 天等实名 + 1—2 天初审 + 7 天管局）。慢的话 20 天左右。

**Q：域名要一直续费吗？**
A：是。按年续费。`.net.cn` 续费价约 ¥38/年，比较稳定，不会像某些新后缀那样翻倍涨。建议开自动续费。
