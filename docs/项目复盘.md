### 第 6 轮 · 原声定稿 + 排版修复（14:00—14:30，**30 分钟**）

**① 原声定稿**

源文件 282,686 字节 → 你确认「整段就是完整的那句话」→ ffmpeg 后期链定稿：

```
atrim=start=0.02:end=17.25, asetpts=PTS-STARTPTS,
highpass=f=110, equalizer=f=300:t=q:w=1.0:g=-2, equalizer=f=2600:t=q:w=1.2:g=3,
afade=t=in:st=0:d=0.03, afade=t=out:st=16.95:d=0.27,
loudnorm=I=-16:TP=-1.5:LRA=11
```

成果 **17.23s / 207,663 字节**（-27%），响度 mean -18.4dB / max -1.9dB **无削波**。
掐头尾静音 + 人声提亮（去 300Hz 浑浊、抬 2.6kHz 清晰度）+ 响度归一化。

**打字节奏与录音同步**：`CHAR_MS=780` / `PUNCT_MS=620`
（原 150/520 会导致 **4.78s 打完 vs 录音 17.23s**，严重脱节）

**② 宣告文字断行修复** —— 三层修法，缺一不可

**症状**：22 字被折成「中华人民共和国，中央人 / 民政府，今天，成立啦！」——"中央人民政府"在行尾被拆开。

| 层 | 手段 | 作用 |
|---|---|---|
| 词完整性 | `word-break: keep-all` + `line-break: strict` | **根本手段**，禁止 CJK 词内断行。`text-wrap: balance` 做不到这件事（它只均衡行长度，不管词完整性） |
| 物理尺寸 | 字号上限 2.6rem → **2.3rem** | **先算账**：22 字 × 1.1em(含字距) ≈ 24.2em，容器可用 932px → 2.6rem 需 1007px（必折行）、2.3rem 需 891px（可一行） |
| 孤字控制 | `text-wrap: pretty` | 让浏览器主动避免行尾孤字 |

**实测效果**（`Range` 逐字测 clientRect 按 top 分组）：
```
lines: ["中华人民共和国，中央人民政府，今天，", "成立啦！"]
```
断点从词中间移到**语气停顿处**，「成立啦！」4 字独立成行居中——**收束感反而比挤一行更强**。

> **教训**：排版问题**先算物理尺寸，别靠试**。

**③ 开国大典页视觉拥挤修复**

截图发现城楼标语与宣告"两排同样大小的字叠在一起"：
- **标语降为建筑肌理**：字号 17→14、不透明度 .86→.42、**y 272→228**（上移到墙体上部，**避开宣告文字所在水平带**——再淡也会形成"背后有字"的干扰）
- **宣告光晕收紧**：`text-shadow` 从 `34px/88px` → `12px/32px`（原半径会糊到身后城楼题字上）

**④ p08 报纸英文 → 中文「日本投降」**

用**透视贴图**（纯本地 Pillow，**0 积分**）：定位四边形（127×24.5px，倾角 11.16°）→ 透视取正 → **从原图外围采样真实光照重建纸底** → 写「日本投降 / 民国三十四年八月十五日 / 号外」→ 逆透视贴回。

## 五、方法论沉淀（可复用）

### 1. 验证铁律

> **改 JS（尤其对象/数组字面量）后必须真跑验证，禁止只做字符串存在性检查。**

配套的最低验证组合：
- **`Range` 逐字测 `clientRect`** —— 判断断行归属，比截图肉眼判断可靠
- **`getComputedStyle()` 量实际值** —— 抓 CSS 优先级冲突
- **`node` 抽出 JS 段求值** —— 抓语法错误
- **Playwright 直连系统 Edge 真点一次** —— 验证交互态

### 2. 静态核验替代方案（浏览器不可用时）

浏览器反复挂起时，用这套组合完成验收**比反复重启浏览器高效得多**：
1. HTML 的 `src`/`href` 引用逐一核验 → 0 失效
2. `data.js` 的资源引用 vs 磁盘实际文件 → 交叉核验
3. curl 对所有 URL 的可达性
4. **线上内容特征比对字节数** → 确认非缓存

### 3. 史实把关清单（历史类教学项目）

| 检查项 | 注意 |
|---|---|
| 国徽 | 1949.10.1 **尚未确定**（1950.6 才审定）——城楼上此时只有主席画像 + 两条标语 |
| 城楼标语 | 1949 年为「中华人民共和国万岁 / 中央人民政府万岁」 |
| 国旗 | 必须按《国旗法》几何精确：四小星各有一角尖**正对大星中心** |
| 报纸文字 | 1945 年中国报纸应为**中文竖排**，不可是英文 |
| 徽标类元素 | **AI 生成完全不可靠**（越南国旗被当成中国国旗）——必须手绘 SVG |

### 4. 技能沉淀

本轮把「透视贴字」方法固化为技能 **`ai-image-text-patch`**，包含：四边形定位 → 倾角计算 → 透视方向实测 → 光照采样重建 → 字体可用性验证 → 边缘羽化 → 按实际显示尺寸验收的完整流程，以及上述 5 个坑的规避方法。
